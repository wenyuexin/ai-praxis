# 研究方法的设计意图

本文解释研究方法为何分别关心认识、可信度和正文交付，以及为何共用责任必须配合对象适配与任务裁剪。执行入口是 [`rules/research-method.md`](../rules/research-method.md)，本文不是日常前置阅读，也不复制执行清单。

## 1. 三个不同的判断

研究者掌握了什么、主张依据有多可靠、读者从正文获得什么，是三个相互支持但不能替代的判断。

一个事实得到来源支持，仍可能没有连接到整体模型；研究者能从源码理解过程，正文却可能只留下压缩结论；正文流畅也可能掩盖错误推断。因此，Evidence 和理解交付需要分别检查。把研究者已读的材料全部交给验收读者，会掩盖正文自身的缺口。

现有 [`概念顺序 incident`](../incidents/incident-research-document-concept-order.md) 已记录结构和 Evidence 合规仍可能缺少连续理解的情形。它不能据此解释所有研究失败，也不能把之后任意理解问题自动判成同一具体复发。

## 2. 为什么独立承接研究方法

材料吸收解决已有输入是什么、能支持什么、怎样回流。产物组织解决研究单元、正文与辅助层怎样分工。研究推进还需要连接目标、重要遗漏、下一步行动、综合解释和结束判断。

把这些责任全部扩进 Ingest，会改变输入吸收能力的边界；全部写入产物组织文件，则使开展研究和调整目录都要付出同样阅读成本。独立方法文件让开展研究与组织成果按任务进入，Evidence、落位和文件身份继续由既有 owner 裁决。

这里的最低责任不意味着一套固定工作流。研究可以从模糊问题或新材料开始，发现也可以改变目标；关键是调整有依据，结束判断与实际所得相符。

## 3. 共用责任与对象特有动作

不同对象可共用目的、覆盖、解释和交付判断，但证据形态不同：实现研究沿接口和执行路径；论文连接问题、方法与论证，常需比较公式、图、附录和实验；概念研究关注定义与区分条件。

主题/对象/混合型是研究单元的责任划分，论文/实现/概念等是调查方法选择的线索。两个维度不能相互替代，也不能根据使用了论文就把按技术问题组织的正文强改成整篇论文研究。

方法提示允许分析与综合超出原文措辞，但结论性质仍受来源约束。公开材料未定义一个步骤时，解释缺失影响通常比补出一个貌似合理的机制更有价值。

## 4. 当前实践支持到哪里

2026-10-30 的方法设计结合了 Mem0 实现研究与 A-MEM 论文研究。当前可核查的产物是 [Mem0 整体解释](../../../agentic/02-single-agent/memory/project-studies/mem0/overview.md)、[检索专题](../../../agentic/02-single-agent/memory/project-studies/mem0/retrieval.md) 和 [A-MEM 论文研究](../../../agentic/02-single-agent/memory/long-term-memory/papers/a-mem_2502.12110.md)。

这些产物展示了整体关系、过程推演、条件变化和论文论证核查的结合，可作为写作与检查的实际样本。它们不独立证明改前缺口、冷读实际回答或方法收益的因果来源；历史试验记录与当前正文是不同材料。

两案主要是静态阅读、分析、综合与 AI 诊断，没有模型复现实验或真实人类学习效果测量。技术概念、理论和比较研究的动作提示包含设计推导，不能写成这些类型都已在该轮得到验证。方法的约束力与验证范围分别判断，依据见 [`evolution-design.md`](../../design/evolution-design.md)。

## 5. 怎样避免新的形式合规

如果方法变成固定目标表、覆盖表和问卷，协作者仍可能只填字段而没有形成认识。因此，方法主规则以“当前缺什么，怎样补，能判断什么”连接行动，不以文件数、篇幅或题量代理质量。

问题树适合持续维护一条递进主线，不能因局部问题涉及机制就自动创建。独立读者可发现写作者的盲点，但检查题目过窄时仍会漏掉重要内容；冷读也不能测量所有真实学习收益。

新增分层是否值得，最终要看真实任务的最小必读集、行动选择与产出。若普通研究仍被迫通读能力、规则、intent 和设计，应收紧入口和重复职责，而非继续增加一层导航。相关长期原则见 [`organization-principles.md §10`](../rules/organization-principles.md)。
