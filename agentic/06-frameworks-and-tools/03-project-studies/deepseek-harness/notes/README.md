# Notes（研究辅助材料）

本目录承接 DeepSeek Harness 研究过程材料，服务于 traceability 与后续维护，不作为主要阅读入口。

命名约定：

- `general.md`：一般研究过程材料与临时观察
- `source.md`：上游来源摘录、源码核验路径、长引用与失败搜索
- `evidence.md`：Claim-Source 对照、Evidence 状态与待补证点
- `deep-research-question-tree.md`：深度研究问题树（主线问题 + 分层子问题 + 已知/待确认/下一步），研究推进脚手架主入口
- `reflections.md`：基于现状的个人观察、直觉与阶段性理解（非正式结论）
- 也可按机制或来源命名：`<mechanism>.md`、`<source-name>.md`

规则：进入本目录的材料已完成对象归属判断；不要把 `notes/` 当成临时文件的镜像或正式正文的替代品。内容压实后应提炼为版本化正文或机制专题，研究脚手架保留未闭环问题。
